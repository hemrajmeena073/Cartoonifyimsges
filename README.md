## 📌 About The Project

**Cartoonify Images** is a Python-based image processing project that transforms normal photographs into **cartoon-style images** using computer vision techniques.

The project demonstrates how image filtering, edge detection, grayscale conversion, and color processing can be combined to create a cartoon effect.

---

## ✨ Features

* 🖼️ Convert images into cartoon-style images
* 🎨 Apply image filters
* 🔍 Edge detection
* ⚫ Grayscale processing
* 🌈 Color enhancement
* 💾 Save the cartoonified image
* 🐍 Simple Python implementation

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/hemrajmeena073/Cartoonifyimsges.git
```

### Install OpenCV

```bash
pip install opencv-python
```

### Run the project

```bash
python main.py
```

> Replace `main.py` with the actual Python filename if different.
